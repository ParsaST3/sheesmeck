# انتشار شبیه‌سازی FlyWire روی GitHub Pages

این پوشه برای سایت GitHub Pages آماده شده است. فایل مغز در سه بخش کوچک‌تر از ۱۰۰ مگابایت قرار دارد تا GitHub آن‌ها را بپذیرد؛ صفحه پس از انتشار بخش‌ها را از مخزن عمومی می‌خواند و دوباره به فایل FLYC تبدیل می‌کند.

## انتشار

۱. در GitHub یک مخزن **Public** بساز و نام پیش‌فرض شاخه را `main` نگه دار.
۲. محتویات همین پوشه را در ریشهٔ مخزن قرار بده؛ پوشه‌های `brain` و `.github` هم باید منتقل شوند.
۳. در مخزن، از **Settings → Pages**، گزینهٔ **GitHub Actions** را به‌عنوان منبع انتشار انتخاب کن.
۴. منتظر بمان اجرای workflow با نام **Deploy GitHub Pages** تمام شود. نشانی سایت از صفحهٔ **Settings → Pages** نمایش داده می‌شود.

آدرس فایل‌های مغز به‌صورت خودکار از نام کاربر و مخزن سایت ساخته می‌شود. مخزن باید عمومی باشد تا مرورگر بتواند بخش‌های مغز را دریافت کند.
